## 📌 About The Repository

This repository contains the implementation of **KTU M.Tech Computer Science and Engineering Semester 1 Computing Lab experiments**.

The experiments cover fundamental and advanced **Machine Learning algorithms**, including:

- Decision Tree Learning
- Bayesian Learning
- Classification Algorithms
- Clustering Techniques
- Neural Networks
- Model Evaluation Methods


All programs are implemented using **Python** with popular machine learning libraries such as:

- NumPy
- Pandas
- Scikit-Learn
- TensorFlow
- PyTorch-compatible concepts
- pgmpy
- Matplotlib

# ⚙️ Installation


Clone the repository:

```bash
git clone https://github.com/shadil-rayyan/ktu-mtech-cse-s1-computing-lab.git

cd ktu-mtech-cse-s1-computing-lab
```


Install dependencies:

```bash
pip install -r requirements.txt
```


Or install manually:


```bash
pip install numpy pandas scikit-learn matplotlib seaborn tensorflow pgmpy networkx
```

# ▶️ Running Experiments

cd 06-KNN-Algorithm
